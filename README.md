# Invisible Violin

Play a virtual violin with hand gestures.

- `index.html`: browser version.
- `ios/`: native iPhone app, version 1.0 build 6. Open `ios/InvisibleViolin.xcodeproj` in Xcode. See [iPhone setup and build instructions](ios/README.md).
- `ios-support.html` and `ios-privacy.html`: published support and privacy pages.

The iPhone app includes on-device MediaPipe hand tracking, synthesized audio, an animated guide, finger calibration, and full-screen playing.
